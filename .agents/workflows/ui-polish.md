# UI Polish Workflow

Run a final visual and interaction polish pass on a target page or component.

## Usage

```text
/ui-polish [target]
```

## Steps
1. Load `.agents/skills/impeccable/reference/polish.md`.
2. Inspect alignment, concentric border radii, spacing rhythm, and color tinting.
3. Ensure no pure black or harsh un-tinted gray is used.
4. Verify micro-animations use purposeful spring physics instead of bounce easing.
5. Apply drop-in XAML / CSS improvements.
